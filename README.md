# Basic Info Site

Serving static web pages with node.js. Supports importing html file in html.

## Skills demonstrated

- Creating a server and listening for requests on a port with http node module

- Reading file content using the fs module from node.js

- Replacing parts of html file content with referenced html file content

- Responding to HTTP requests by serving different html pages according to the requested url with the help of http module from node.js
